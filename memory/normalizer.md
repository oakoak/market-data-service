- [2026-09-14] **Open gap, NOT fixed in this change (needs collector-agent + normalizer-agent coordination, spans both directories):** `Config.stream_prefix` in BOTH `src/collector/config.py` and `src/normalizer/config.py` is `f"raw:{exchange}:{symbol.lower()}"` -- it does **not** include `segment`. Binance spot BTCUSDT and USDT-M perp BTCUSDT (same symbol string, different segment) would therefore collide on identical Redis stream names (`raw:binance:btcusdt:trades`, `:depth`, etc.) if both are run concurrently for the same symbol, which Phase B's own premise (spot + USDT-M perp side by side) implies will happen. Not fixed here because fixing only normalizer/config.py would break consumption entirely (collector and normalizer must agree on the stream_prefix, and src/collector/ is out of normalizer-agent's scope this change) -- this needs a coordinated fix across both configs, flagged loudly for whoever picks up cross-segment concurrent deployment next.
